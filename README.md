# Alma De Piedra — E-commerce Joyería de Autor

Sitio e-commerce de **Alma De Piedra (ADP Joyas)** desarrollado sobre WordPress + WooCommerce + Kadence.

## Estructura del repositorio
- `wp-content/themes/kadence-alma-de-piedra/` — Tema hijo de Kadence (`style.css`, `functions.php`, `front-page.php`, `page-nosotros.php`) con el sistema de diseño *Serene Mineral Luxury* y efecto hover en tarjetas de producto.
- `stitch_e_commerce_platform_development/` — Sistema de diseño (`DESIGN.md`) y pantallas de referencia creadas en Stitch.

## Stack
- WordPress + WooCommerce (CLP, despacho RM/V/VI y Blue Express, transferencia bancaria directa)
- Tema Kadence + Kadence Blocks + tema hijo `kadence-alma-de-piedra`

Sitio desarrollado por [Innova IA Studio](https://www.innovaiastudio.com/).
